# Schatten and rank extensions of Clarisse and Wocjan's permutation classification

**Authors:** Haobo Ma, Wenlin Zhang

Extending Clarisse and Wocjan's orbit bound and answering their norm-dependence question (arXiv:quant-ph/0504160v2, 14 June 2005, Theorem 3, p. 3, equation (2); Section V, p. 6; Definition 1, p. 2), we prove for every r >= 1 and d >= 2 that mixed single-party and Bell-pair states distinguish tensor-index permutations exactly up to the four row-set symmetries. Consequently the prior orbit bound is exact for norm equality. The same classification holds for rank and every Schatten functional with 0 < p <= infinity, p != 2, including quasi-norms below one; all permutations preserve the Hilbert-Schmidt norm. We also give an adaptive identifying family of at most 2r - 1 states and a Bell-state proof of the known partial-transpose incomparability.
